Typed, editor-managed reusable content blocks for MRN WordPress sites.

== Description ==

MRN Reusable Block Library provides shared reusable content types, ACF field
contracts, and rendering entry points. The active theme owns final presentation.

== Changelog ==

= 0.2.0 =
* Added a Layout Class control after Anchor ID for every reusable layout.
* Sanitized comma-separated classes, accepted optional leading periods, and
  rendered the resulting classes on each layout's outermost element.
